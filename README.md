# Dubito

Jeu de bluff de cartes multijoueur pour PC (Steam), de 2 à 6 joueurs assis autour d'une table en 3D.
On pose des cartes face cachée, on ment sur leur valeur, et le suivant doit choisir : **croire, douter ou brûler le tas**.

**État** : conception terminée, développement Unity à venir (voir [docs/ROADMAP.md](docs/ROADMAP.md)).
